# React Demo App

React + Vite demo with Weather, Dog Info (pagination), Stop Watch, Shopping Cart, and Auto-focus Search. Built for local development and optional GitHub Pages hosting.

## Run locally

```bash
npm install
npm run dev
```

Open: **http://127.0.0.1:5173/react_demo_app/**

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages (manual)

When ready to deploy:

1. Create or use repo: `akshayatharun-cmyk/react_demo_app`
2. Push this folder to `main`
3. Run:

```bash
npm run pages:publish
```

4. GitHub → **Settings → Pages** → Source: **`gh-pages`** branch, **`/ (root)`**

Live URL: https://akshayatharun-cmyk.github.io/react_demo_app/

Base path `/react_demo_app/` is set in `vite.config.js` for GitHub Pages.
